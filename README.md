### ⚙️ Engineered For Performance

| Feature | Implementation |
|---------|----------------|
| 🎯 **60 FPS** | Single `<canvas>` · `requestAnimationFrame` · delta-timed physics |
| 🧲 **Magnetic Hover** | Throttled `getBoundingClientRect` hit-testing |
| 💥 **Click Shockwave** | Pooled particle system — zero per-frame allocations |
| 🌊 **Fluid Trailing** | Segmented ring with dual-layer `lerp` easing |
| ♿ **Accessible** | Auto-disables on `prefers-reduced-motion` & touch devices |
| 🧩 **Encapsulated** | ES6 class · no global pollution · `destroy()` cleanup API |
